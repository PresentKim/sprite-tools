원본 유지더 많이 합침

이 수 이하가 되는 가장 약한 병합 강도를 자동으로 찾습니다. 투명 색은 세지 않습니다.

자동은 같은 색이 이어지는 길이로 확대 배율을 찾습니다.

보간 없이 픽셀을 그대로 키웁니다(최근접 이웃).

투명하지 않은 픽셀을 감싸는 영역으로 자른 뒤, 사방에 이만큼 투명 여백을 더합니다. 이미 같은 모양이거나 완전히 투명한 이미지는 건너뜁니다.

이미지에 쓰인 색을 팔레트 PNG(색 1개 = 1px, 한 줄)로 뽑습니다. 많이 쓴 색부터, 투명 색은 제외하고 알파는 255로 맞춥니다. 256색을 넘으면 먼저 색상 줄이기가 필요합니다.

저장하면 '팔레트 적용'에서 바로 고를 수 있습니다. 파일이 하나일 때만 사용할 수 있습니다.

0 = 자동 (개수의 제곱근을 올림)

목록의 모든 파일을 이름의 숫자 순서(frame-2, frame-10)대로 한 장에 합칩니다. 칸 크기는 가장 큰 이미지 기준입니다.

색상 순서는 이미지에 처음 나온 순서이며, 255색을 넘는 이미지는 먼저 색상 줄이기나 팔레트 적용이 필요합니다.

저장 방식

폴더에서 찾은 파일은 하위 폴더 구조를 유지합니다.

<이름>-0001.png, <이름>-0002.png … 로 저장됩니다.
